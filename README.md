# Angadi Jyothsna — Portfolio

Personal portfolio website built with React, TypeScript, and Vite showcasing my projects, internships, technical skills, education, certifications, and achievements in Data Analytics, Data Science, and Software Development.

## Tech Stack

- **Frontend:** React 19, TypeScript, Vite
- **Animations & Icons:** Framer Motion, Lucide React, React Icons
- **Contact Form:** Formspree / EmailJS (with Gmail fallback)

## Features

- Responsive layout with **Dark / Light** theme toggle
- Sections for About, Education, Skills, Experience, Projects, Certifications, Achievements, and Contact
- Resume download and internship document previews
- Interactive contact form with Formspree, EmailJS, or direct Gmail compose support

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Jyothsna306/jyothsna-portfolio.git
   cd jyothsna-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. *(Optional)* Configure the contact form by copying `.env.example` to `.env` and adding your Formspree endpoint or EmailJS keys.

4. Start the development server:
   ```bash
   npm run dev
   ```

## Scripts

- `npm run dev` — Start local development server
- `npm run build` — Type-check and build for production
- `npm run preview` — Preview the production build locally
